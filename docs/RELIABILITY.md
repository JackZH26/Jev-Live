# 主持稳定性迭代

[简体中文](RELIABILITY.md) · [English](RELIABILITY.en.md)

范围：按原清单推进第 1–6 项：稳定性修复、平台联调、完整流程、自然主持与五语语音、恢复、配置与分发。第 7–8 项高级角色布局与新增平台暂缓，自动玩由另一会话负责。

## 已修复并验证

旧叠加层把状态请求、音频下载和解码异常都计入 `audioErrors`，且下载前就标记台词已播放。现将状态和音频错误分开，记录受限错误码，不记录凭证、地址或观众内容。音频只在实际启动后确认，启动前失败最多重试三次并退避；过时台词丢弃，不在重连后补播。记录开始、结束、恢复、过期和中断；刷新页面通过会话存储避免重复播放同一台词。

`node scripts/smoke-overlay-recovery.cjs` 使用真实 Chromium/Web Audio：注入一次音频 503 后恢复播放；一次状态 503 不增加音频错误；刷新不重复播出；下一句正常播放。它使用明确的本机测试音，不连接游戏或平台账号。

这修复了确定存在的重试缺陷并提供诊断，但不能据此断言前一轮三次错误的根因已经确认。新版还需要完整时长测试和真实平台听音验收。

## 本地自然语音

`services/local_voice.py` 为 Qwen3-TTS-0.6B 提供本机 HTTP 服务；模型从仓库外本地路径加载，运行时禁用 Hugging Face 联网，拒绝浏览器 Origin 和非本机 Host，并限制长度及并发。CPU/GPU 性能和五语言语音尚在本轮测试，不默认替代已有系统声音。

## 验收地址

优先使用已配置的 X Live Studio 私密事件。固定后台入口是 `https://studio.x.com/live`，需要登录持有该直播的 X 账号；它与单场事件链接不同。平台单场事件有时长和超时限制，重建事件后详情链接会变化，不能承诺一条事件链接永久直播。YouTube 频道当前仍在首次开通等待，真实验收必须等权限生效。
