# X 直播配置

[简体中文](X_SETUP.md) · [English](X_SETUP.en.md)

JEV Studio 使用 **X Live Studio 的官方 RTMPS 推流源**，作为 YouTube、Twitch 之外可独立勾选的第三路输出。游戏仍从 Steam 库添加和启动；首测为 Enter the Cube Playtest（5272970）。自动／手动模式只影响游戏输入。

## 一次配置

1. 用自己的账号打开 [X Live Studio](https://x.com/i/live-studio)。账号需具有该入口和外部编码器直播权限；浏览器登录并不等于软件取得 OAuth 授权。
2. 在 Manage Sources 选择已有推流源，或创建一个靠近所在地的源。源名称只是连接标签，不是游戏开发工程。
3. 打开 Encoder setup，在 JEV Studio 的“连接与设置 → 配置 X 直播”填写名称、RTMPS 地址和 Stream key，点击“加密保存推流源”。地址和密钥只在本机保存；不要放进 Git、聊天或截图。
4. 返回工作台，勾选 X。可以只播 X，也可以与 YouTube / Twitch 组合。连接／准备所选 OBS，选择 Steam 游戏窗口并应用；新增输出后需重新应用窗口。

现有安装升级后保留原有平台勾选，不会自动启用 X。“移除本机配置”不会删除 X 后台的源。更换源时重新填写地址和密钥。

## 每次直播

1. 在软件预览中核对 Steam 游戏画面；点击“开始直播”向所选推流源发送画面及游戏进程声音。
2. 在 X Live Studio 新建直播，选择相同源，填写标题并检查 Audience。首次建议选择 **Private**；它只在 Live Studio 内可见。确认预览后 Go Live；也可在 X 后台配置预约／自动开始。
3. 软件中的 YouTube 私密选项**不控制 X**。本版本不自动创建 X 直播、不发布 X 帖子、不同步 X 标题，也不读取或回复 X 聊天。保存推流源和 OBS 正在发送均不代表 X 已开播。
4. 结束时在 JEV Studio 停止输出，并在 X 后台确认直播结束。软件清除 OBS 的临时推流密钥，保留本机加密源以便下次使用。

选中 Twitch 会公开直播。所有所选平台均准备成功后软件才开始发送；YouTube 权限未开通时可以取消该平台，仅选择已就绪的平台。

## 参数与限制

X 使用独立 OBS：H.264 High、1920×1080、60 fps、AAC 128 kbps、三秒关键帧，视频码率读取软件设置（默认 6000 kbps）。当前预设按新版官方 Live Studio 帮助升级为 60 fps；现有源在停止推流并重新准备 OBS 后更新。

本接入不使用普通 X OAuth 代替直播源权限。软件没有实现 X 直播事件的自动创建／结束或 24 小时轮换；X 单场直播最长 24 小时，超时结束的事件需要重新创建。请勿把当前短时验收当作无人值守 24 小时验收。

私密主持演示可明确启用本地模拟评论投影：叠加层设置 `simulation`，每条注入评论也标记为模拟，面板显示 **SIMULATED CHAT**，昵称带 **[SIM]**。这些评论用于本地语音回复测试，不会发到 X，也不是读取 X 的真实观众。常规 X 叠加层仍不显示其他平台聊天。直播主持默认英文；支持的评论语言使用对应语言回复，其余默认英文。
