# 多语言与双语文档约定

[简体中文](I18N.md) · [English](I18N.en.md)

首期支持 `zh-CN`（简中）、`zh-TW`（繁中）、`ja`（日语）、`ko`（韩语）、`en`（英语）。默认简中；顶部语言选择即时生效并保存。语言设置不启动、停止或切换游戏和推流，也无需重新登录。

Steam 游戏库与窗口控制文案集中在 `shared/locales/steam.ts`，遵循相同的五语言资源约定。

界面资源位于 `shared/locales/ui.ts`，运行事件与错误位于 `shared/locales/runtime.ts`；`shared/i18n.ts` 提供统一的类型和格式化。每行依次为键名及五语言翻译，类型和测试检查列数、唯一键与占位符。通过 `t(locale, key, params)` 显示，禁止在界面新增硬编码用户文案。品牌名、程序路径和技术标识保持原样。

后台通过 `message(key, params)` 生成不依赖语言的事件；前端显示时翻译。因此已记录的日志也会跟随语言切换。参数不能带凭证；底层第三方错误可能保留原始技术语言，正常操作提示均提供五语。时间由 `Intl` 按当前语言显示。旧配置自动补上默认语言。

新增语言时：扩展 `locales`、资源行类型及所有资源、设置校验和选择器；增加字体和长文本检查；运行 `npm run check`、`npm test`、`npm run build` 与 `node scripts/smoke-i18n.cjs`。后者使用独立本机数据，验证五语言错误、作者链接、保存后重启、控制状态不变，以及最小 1080px 宽度。

说明文档成对维护中文与英文，并在顶部互相链接。中文主文档通常为 `NAME.md`，英文为 `NAME.en.md`；已有英文规范（如 SECURITY）保留原文件名，中文用 `.zh-CN.md`。英文 MIT `LICENSE` 是正式条款，中文文件标注参考译文。架构方案是历史计划，实际能力以两语验收记录为准。

作者区使用 JackZH26，醒目展示 X [@jackzhj](https://x.com/jackzhj) 与“欢迎关注交流”。新增功能同时更新两语文档与五语资源，不能只维护导航文字。
