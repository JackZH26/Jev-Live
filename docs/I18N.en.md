# Localization and bilingual documentation

[简体中文](I18N.md) · [English](I18N.en.md)

Phase 1 supports `zh-CN` (Simplified Chinese), `zh-TW` (Traditional Chinese), `ja` (Japanese), `ko` (Korean) and `en` (English). Simplified Chinese is the default. The header selector applies and saves changes immediately without starting, stopping or switching game control or streaming, or requiring sign-in again.

Steam library and window-control copy lives in `shared/locales/steam.ts` under the same five-language resource contract.

UI resources live in `shared/locales/ui.ts`, and runtime events/errors in `shared/locales/runtime.ts`. `shared/i18n.ts` supplies shared types and formatting. Each row contains a key followed by all five translations; types and tests check column counts, unique keys and matching placeholders. Use `t(locale, key, params)` rather than adding hardcoded user-facing copy. Brand names, paths and technical identifiers remain unchanged.

The backend uses `message(key, params)` for language-independent events translated at display time, allowing existing logs to switch languages too. Parameters must never contain credentials. Low-level third-party errors may retain their original technical language; normal operation messages have five translations. Times use `Intl` with the current locale. Old configuration receives the default language automatically.

To add a language, extend `locales`, resource tuple types and all resources, settings validation and the selector. Check fonts and longer text. Run `npm run check`, `npm test`, `npm run build` and `node scripts/smoke-i18n.cjs`. The last test uses separate local data and verifies translated errors, the author link, persistence across restart, unchanged control states and the minimum 1080px window width.

Maintain explanatory documents in Chinese/English pairs with reciprocal links at the top. Chinese normally uses `NAME.md` and English `NAME.en.md`. Existing English conventions such as SECURITY retain their filenames; Chinese uses `.zh-CN.md`. The English MIT `LICENSE` is authoritative and its Chinese counterpart is explicitly a reference translation. Architecture documents are historical plans; the paired acceptance records describe actual implementation.
