# 0.1.4：游戏断连验收修正

[简体中文](ITERATION_014.md) · [English](ITERATION_014.en.md)

作者：JackZH26 · 𝕏 [@jackzhj](https://x.com/jackzhj)，欢迎关注交流。

继承 [0.1.3 本地五语语音与恢复改进](ITERATION_013.md)。范围仍为规划 1–6，7–8 暂缓。

2026-09-20 21:19:35（UTC+8），新版三路本机长测记录到游戏观察断开；进程检查也未找到 Steam Playtest 游戏进程。OBS 仍可持续编码最后一帧，因此“输出帧数增长、音频无错误”不能证明游戏仍在运行。尚未确认游戏退出原因，也未把它归因于另一开发会话。

本轮两小时测试已于 21:25 主动中止，**未通过**。原始失败报告保留测试接收器停止所触发的清理错误；补充评估说明主动停止原因为游戏进程消失。三路测试 OBS 已关闭，仅保留私密验收输出。需协调游戏占用/退出原因后，在准确构建上重新测试。

修正：

- 长测采样必须保持游戏观察连接，断开立即失败。
- 游戏断开时直播画面覆盖五语“正在等待游戏画面”，避免把最后一帧显示成持续游玩；恢复观察后自动撤去等待画面。头像、聊天和主持独立保留。
- 不自动操作、重启或接管游戏；不修改另一会话负责的自动玩模块。

类型检查、99 项 TS 测试、构建，以及真实 Chromium 中的断连等待画面/重连撤去/语音重试/刷新不重复播放验证通过。

1–6 仍未全部验收：真实 YouTube/Twitch 互动受资格/授权限制；完整对局、2/8/24/72 小时、整机守护、签名、公共 OAuth、可信更新和新电脑验收仍待完成。X 私密固定后台入口仍为 [Live Studio](https://studio.x.com/live)；版本更新不要求重建当前事件，但播放器可能需要刷新。
