## 结论

复用游戏完整的 Pro BOT AI 来操控直播角色，保留玩家控制器、身份、背包、HUD 和结算。JEV 负责开局、直播、连续对局和监控，战斗时只续期控制授权，不再逐条下发战术指令。必须使用含新接口的 Steam 安装包；旧包明确报不支持，不静默回退。

## 改动前核实的边界

以下路径相对于 ETC 工程 `Plugins/GameFeatures/EtcCore/Source/EtcCoreRuntime/`，描述当前查阅的源码；运行效果必须另以安装后的 Steam 包验收。

| 位置 | 已有行为与缺口 |
| --- | --- |
| `Public/AI/EtcBotTypes.h` | 难度枚举最高档为 Pro，高于 Expert。 |
| `Private/Development/EtcJevBridge.cpp`，`Executor` | 为玩家挂载 BOT Brain 与 Pro Aim，但通过 `SetExternalObjective` 执行外部目标。 |
| `Private/AI/EtcBotBrainComponent.cpp`，`Reevaluate` | 外部控制立即转入 `ReevaluateExternal`；完整自主决策要求 `AEtcBotController`。 |
| 同文件，`TickComponent` | 玩家控制器没有外部控制时直接退出，关闭外部控制不能自动变成完整 BOT。 |
| 同文件，`UpdateSurvival` / `UpdateRecovery` / `UpdateAutomaticTraversal` / `BeginStallWalkOff` | 外部模式跳过自动求生、恢复及部分攀爬脱困；这些行为目前不能靠 Pro Aim 恢复。 |
| 同文件，`RefreshPerception` | 原生视觉与受击感知依赖 BOT 控制器；包含无人机存活/活动状态、装备弹药不足时规避大型无人机等判断。 |
| `Private/Development/EtcJevController.h` | 已有保留玩家控制器的路径跟随适配，可扩展复用。 |

这解释了两种控制方式的功能差异，不能据此认定所有实测死亡都由同一个原因造成。

## 已实现的改动

1. **共用同一套原生大脑。** 将难度、所属房间、感知、阵营和移动控制等 BOT 控制器依赖收敛为共享适配接口。普通 BOT 保持原行为；托管玩家使用 Pro 配置，进入同一战术、补给、恢复、撤离和机关路径逻辑。不能只删类型判断，否则感知与路径依赖仍为空。
2. **保留玩家身份与镜头。** 保留 PlayerController、PlayerState、背包、技能系统、HUD 和结算归属；避免简单更换为 AIController 后破坏身份或相机。原生战斗和玩家镜头只能有一个控制来源，沿用平滑视角控制，验证转向不会妨碍瞄准和脱险。
3. **明确控制权。** 区分手动、外部目标、原生 Pro 三种模式。原生 Pro 接管后，Studio 停止发送 engage/cover/loot 等目标，只维持有时限的控制授权。手动接管、失焦、授权过期、换角色或离开对局时，游戏端释放路径、射击、开镜及移动输入。接口仍限定离线 BOT 对局。
4. **新增能力协商。** 桥接 v3 增加向后兼容字段 `capabilities.nativePro`，实际执行器回传 `control`、`tier`、`brainMode`、`nativeDecisions` 和目标。只有游戏确认 `native-pro` / `Pro` / `running` 才显示已接管；未启动或超时则交还手动。旧版 Steam 包明确显示“不支持原生 Pro”，不能静默回退后仍标为 Pro 全托管。
5. **复用正式开局与续局。** Studio 通过正式 BOT MATCH 按钮进入，开局选房仍走正常选择流程。失败后点击正式返回大厅；确认进入大厅后随机等待 5–8 秒，再匹配。加载时间单独统计，失焦暂停倒计时。
6. **完成 Steam 交付后验收。** 游戏端编译、测试和打包后，更新 Playtest 并从 Steam 安装；核对 BuildID 和运行进程。开发构建或编辑器结果不能代替用户要求的 Steam 实测，也不能把尚未安装的源码当作已上线能力。

已通过：Studio 类型检查与 303 项测试、游戏 21 项原生回归测试（包含控制权和租约释放）、407 项后端/交付工具测试，以及 Shipping 构建和 139 个交付文件校验。它们证明接口与打包回归通过，不代表真实战斗表现。

## 测试与判定

- 先验证控制权和身份：中途手动接管、失焦、会话断开、穿门、死亡、回大厅均无残留输入，伤害/击杀/名次归属于直播角色。
- 验证原生能力实际执行：低血掩体恢复、换弹换枪、宝箱补给、机械威胁、黄房撤离、攀爬与机关脱困；日志必须记录真实 Brain 模式及结果，不能仅记录客户端期望值。
- 完成至少 5 局真实 BOT 冒烟及连续续局，再对比 20 局；最终单独进行 100 局评估。统一敌人数量/难度和游戏规则，保留所有失败与异常。报告胜率、前十率、名次中位数、玩家击杀/伤害、无人机击杀和卡住时间；不混淆机械击杀与玩家击杀。
- Pro 是游戏最高难度档，接入完整能力不等于保证每局第一；先测原生基线，再只针对复现的问题优化。
