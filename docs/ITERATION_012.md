## 已实现并验证

- 叠加层区分状态与音频错误；音频启动前失败有限重试，刷新不重复播出，过期内容不补播。真实 Chromium 注入故障验证通过。
- 主持增加安静/适度/积极三种节奏；菜单阶段加大间隔，游戏中使用短句，状态变化去抖。同平台相同问题合并、跨平台轮换回答、单观众冷却与有界短期记忆。记忆最多 200 人、30 分钟，仅存内存。
- 本机关键词过滤：不展示匹配聊天，不生成对应回复；不删除或修改平台内容。生成文本同样经过过滤。
- 本地 Qwen3-TTS 接口、五语选声、超时与字幕降级。默认继续使用 Windows 声音，未把自然语音性能标记为合格。
- 当前会话输出恢复：10 秒观察期、最多 5 次有退避的重试，原生网络重连期间不重复重启；停止会取消待执行重试。真实独立 OBS 进程崩溃/重启/本机收流测试通过。此功能不自动操作游戏、不接管历史进程、不重建已结束的平台直播事件。
- 五语开播检查页，显示游戏、账号、OBS、采集、模型与语音的具体阻塞项。检查本身不推流。
- 每用户 Windows 安装器配置，保留用户数据，不默认开机启动或自动安装更新。当前无代码签名。

固定入口：[X Live Studio](https://studio.x.com/live)。使用直播所属的 `@jackzhj` 登录。

2026-09-20 20:00（UTC+8）创建了私密事件，详情链接仅向账号所有者交付。平台显示 Private；已看到 Steam Enter the Cube Playtest 大厅与头像，播放器时间、解码帧数和音频字节增长。OBS 源为 1080p60；当时平台播放器自动选择 480p，不能把源端参数写作平台 1080p60 已验收。单场事件链接可因重建而变化，固定后台入口可复用。

## 自然语音实测

在 Core Ultra 7 265K / RTX 5070 Ti 16GB 上，Qwen3-TTS 0.6B CPU 合成短句：简中 93.2 秒、繁中 97.8 秒、日语 30.3 秒、韩语 27.4 秒、英语 46.5 秒。五份 WAV 均已生成，但不满足实时互动延迟要求。

CUDA 12.8 / PyTorch 2.10.0 在同时运行旧三路长测及真实 X 输出的负载下，首句触发超时（客户端约 41.8 秒），GPU 服务已停止。需在释放旧测试资源后复测冷启动、热推理、游戏帧率和显存；不能依据模型加载成功切换默认声音。音质仍待人工听音。

服务仅监听回环地址，拒绝外部 Host 和浏览器 Origin，运行时禁用模型联网；文本长度、并发、生成时长、GPU 分配和返回音频有上限。安装脚本下载固定模型版本到仓库外，安装期间需要网络。
