# JEV + BOT 基础战术与自然镜头

[English](COMBAT_STRATEGY.en.md)

2026-09-21 的目标同时包含正式名次、击杀和游戏记录的伤害。它们分别验收；存活得久、输出多和单次夺冠不能互相替代。JEV 选择战术目标，桌面端处理紧急优先级，BOT 执行连续移动、瞄准、武器输入和机关动作。禁止读取隐藏敌人、未来坍缩顺序，保留 19 个 Regular 对手和正常游戏物理。

## 优先级

1. 手动接管、失焦、过期观察立即释放；死亡与结算走正常流程。
2. 腾空与攀爬完成当前身体动作；活动危险立即撤离。黄房无敌人时优先去连接的白房，覆盖搜刮、补弹和治疗。
3. 受击先寻找近期实际看见的威胁和附近有效掩体；有掩体先移动，抵达后给反击留出窗口，避免逐帧在躲藏和攻击间切换。
4. 没有敌人或近期受击时，缺血且有恢复道具则治疗；按实际弹匣容量补弹；再处理装备升级。危险或威胁可以打断维护。
5. 选择有收益的可见交战，在有效射程内利用当前位置，不为贴近敌人而无条件冲出掩体。准备充分时短暂守备并穿插房内观察，不持续被动等待，也不为了移动而反复进入机关房。

## 操作如何落地

| 操作 | 原生执行与验证要求 |
|---|---|
| 开局选房 | 读取真正显示的选房界面，仅使用公开物资点、热点和出口数；调用同一选房操作锁定，仍等正常倒计时共同入场 |
| 安全补弹 | 桥接上报武器的 `MagazineSize`，按 `magazine < capacity` 选择正常换弹；未知容量不猜测，7 发满弹霰弹枪不会反复装填 |
| 更换好枪 | 看见并到达更高等级枪械后，重新核对满背包与弱主武器，激活玩家的普通丢枪能力，再由普通重叠拾取获取新枪；保留固定副武器 |
| 治疗 | 使用背包已有道具的公共操作，施法期间保持等待；受击、敌人或危险可中止，不修改生命值 |
| 蹲伏、蹲走 | 接近有效掩体的最后一段使用蹲走；攀爬、冲刺与机关专用姿态优先；接管时释放 |
| 右键瞄准、狙击镜 | 复用原有 ADS 能力输入和 SR01 镜头，命中门限依据真实镜头与目标夹角，不绕过射击规则 |
| 跳跃、攀爬、冲刺 | 复用 BOT 机关提供器和玩家 GAS 输入，保留落地、前向输入、可攀表面和动作期间的导航约束 |
| 攻击方向 | 使用实际视野及短期最后目击位置；未看见攻击者时有界转头搜索，不凭隐藏坐标直接锁定 |
| 数据验收 | 分别记录正式名次、击杀、发射数、游戏结算伤害字段；缺失伤害字段记为未提供，不能用发射数换算 |

操作是否可调用与何时实际触发是两项检查。没有遇到狙击枪或可攀表面的对局，不能算开镜或攀爬验收通过。手雷等未新增到本轮战术接口的操作不能宣称已全面覆盖。

## 镜头

2026-09-21 后续优化：按手中实际武器选择交战距离；近距离优先已装弹的自动武器，远距离再考虑狙击枪，火箭筒保留近距离禁射范围。切枪时释放旧枪的瞄准能力，再由新枪正常接管。修正 `SMG01` 名字包含 `MG01` 导致的分类问题，普通对手 BOT 的难度参数保持原值。

到达掩体后，健康且有弹的 AI 获得 1.6 秒还击窗口；短时间内再次受击不会立刻取消还击。仍然暴露且持续超过 3 秒的掩体移动会重新评估，避免无限躲避。低血量、无弹、失去可见目标和房间危险优先处理。短暂保持同一可见目标，减少反复换目标重置瞄准。

镜头加入连续可见方位的角速度补偿，目标切换、失去视野、卡帧和人工接管都会清除估计。算法测试中，12°/s 移动目标在 30/60/120 Hz 下的稳定误差由约 2.75–2.90° 降为 0.25/0.15/0.10°，且仍符合原速度和加速度限制。这是数学跟踪测试，不是实战命中率或胜率结论。

原先移动朝向、90° 扫视、固定周期 360° 环视和瞄准可分别写镜头。新的玩家镜头通过一个执行器合并目标：机关转移优先，其次战斗，再次观察，最后行进。只改变自动玩家，普通敌方 BOT 的瞄准难度保持原样。

采用带速度状态的阻尼转向，限制最大角速度与角加速度，保留目标变化时的连续速度，按最短角度跨越 ±180°。常规水平转向上限 150°/s，战斗/机关 240°/s；俯仰 110°/s。卡帧最多按 50 ms 推进，禁止把积压转向压缩成一帧。常规观察使用短暂且有间隔的小角度目标，取消固定整圈旋转。手动接管清空动量。

这些是候选参数，需要以直播画面与实测轨迹共同校准。控制旋转平滑不代表碰撞相机、传送揭幕、开镜 FOV 等所有画面变化已验收。

## 验收记录

桌面规则和原生实现已进入开发候选；以最后的构建回执、输入快照和实机结果为准。代码检查不能证明胜率提高。此前修复候选的 Steam 完整复测为第 6 名、0 击杀，详见[版本与停滞审计](STRATEGY_AUDIT_20260921.md)。本轮新增能力不能继承旧版成绩。

首个本地 Shipping 候选 `20260921-07` 完整实测为第 16 名、0 击杀、游戏记录伤害 9（Jev 返回 23 次，结束后确认手动释放）。已观察到选房锁定、蹲伏行走和 ADS 输入。643 对连续游戏镜头采样中，没有超出配置速度上限加 3° 采样容差的异常跳转，实测最大水平转速 161.3°/s。这只证明已经观察到的执行环节，不能证明战斗更强。日志暴露出选择远处掩体、丢失敌人视野的问题；下一版限制掩体目标切换，撤退时检查实际见过的敌人方向，并在降低镜头速度上限时连续减速。

分场景验证选房、补弹、换枪、治疗打断、掩体反击和所有实际使用的姿态，再运行完整比赛；每次改版本重新计算成绩。镜头检查包括 30/60/120 Hz、转向反转、跨角度边界、卡帧和手动释放。回执及含私密数据的直播画面保留在本机，不提交 Git。
