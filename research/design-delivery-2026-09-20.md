**JEV Studio：早期调研与设计交付记录（开发前）**

这是概念阶段的历史记录；后续 Steam 游戏库工作台开发以[当前验收记录](../docs/PHASE1_STATUS.md)为准。

调研日期：2026-09-20。

方案已明确自动玩／手动玩双模式：两种模式都由 AI 自动解说、语音回答和文字回复，区别仅在游戏操作由 AI 还是用户完成；文字发送能力依各平台权限。直播中可切换模式，互动链路持续运行。

- [完整调研与设计方案](../JEV-虚拟主播软件-调研与完整设计方案.md)：开源项目对比、JEV 边界、产品流程、游戏适配、OBS 多输出、平台权限、角色互动、运行恢复、成本与开发验收。
- [交互式界面原型](../prototype/index.html)：用浏览器打开，可选择自动玩／手动玩并在模拟直播中切换；也可切换平台、拖动头像和聊天、改变尺寸与透明度、切换横竖屏，并导出布局 JSON。
- [自动玩预览图](../prototype/preview-desktop.png)、[手动玩预览图](../prototype/preview-manual.png)与[竖屏预览图](../prototype/preview-portrait.png)。
- [GitHub 仓库调研快照](github-snapshot-2026-09-20.json)：通过 GitHub API 获取的仓库活动与许可元数据。Open-LLM-VTuber 的 API 许可识别不完整，已在方案中按 LICENSE 正文解释。

原型是本地单文件 HTML，无第三方脚本、账号连接或网络推流。画面、角色和聊天均为概念演示；不代表已安装游戏适配或完成直播系统。文件中的 SVG 头像是占位图形，正式角色仍需选择或制作并取得对应授权。

已使用本机 Chrome 的无头浏览器检查：页面加载、Twitch 聊天隔离、尺寸修改、拖动、模拟启停、竖屏、六个图层的总览、布局导出、390px 窄屏。双模式更新检查包括开播前模式选择、直播中双向切换、自动互动状态保持、静音状态保持、手动模式不显示自动操作按钮，以及结束模拟后保留模式选择。通过的检查没有发现页面脚本错误；未进行真实直播与长期运行验证。

本次未启动真实直播，未修改 OBS、游戏、Steam 或平台账号设置。
